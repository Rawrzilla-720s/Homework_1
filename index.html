About Me

I am a third-year Computer Science student at Georgia State University, minoring in Mathematics. Most of my coursework so far has been in data structures and algorithms, system-level programming, computer organization, and computer networks, alongside the math sequence through Linear Algebra and Numerical Analysis.

The part I keep coming back to is performance and concurrency. Threadoku started as an ordinary Sudoku solver and turned into a project about thread synchronization and load balancing once I tried to make it fast. SecretSociety was similar: the protocol itself was straightforward, and the real work was in handling race conditions between clients. Outside of classes I am on the software team at Rocket Technologies GSU, where I work on thrust vector control for model rockets and autonomous rovers.

I graduate in May 2027 and am looking for entry-level software engineering roles, ideally in systems, embedded, or anything performance focused.

Projects

Personal and team projects, mostly in systems programming and concurrency.

Threadoku

C++ · WebAssembly · Emscripten · April 2025

A multithreaded Sudoku solver compiled to WebAssembly so it runs and animates in the browser. Parallelizing the search and balancing work across threads made it about 63% faster than the single-threaded version.

SecretSociety

Python · TCP Sockets · Threading · November 2025

An IRC-style chat server and client built on raw TCP sockets with a JSON message protocol. It handles many clients at once, so most of the work went into keeping shared channel state consistent across threads.

View on GitHub

Style.Me

Python · Selenium · OpenAI API · November 2025

A Chrome extension that suggests clothing based on a description of what you are looking for. It scrapes retailer pages with Selenium and uses a language model to interpret the query.

PaperKeys

ReactJS · MediaPipe · February 2025

A virtual piano that tracks your hands over a printed paper keyboard and plays notes in real time. Replacing OpenCV with custom anchor-point alignment cut note-detection errors by over 20%.

DiagnAI

A team-built health assistant that walks through symptom screening and returns general medical information. Reworking the async request handling brought query latency down by roughly 35%.
